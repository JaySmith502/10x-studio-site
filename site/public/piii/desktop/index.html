Redact, use the AI,
rehydrate.

Scrub a client spreadsheet, have a model draft the letters, and get the letters back with real names filled in. The real values never leave your machine.

01

Redact

Drop up to 2,000 files. Review what it found, untick anything you want to keep, add extra values to hide, and scrub.

02

Use any AI

The scrubbed file carries placeholders like [NAME-K7QX2M9PDA] instead of names, SSNs and phone numbers. Hand it to whichever model you use.

03

Rehydrate

Drop what the AI wrote on the Rehydrate tab. The real values go back in, even when the file type changed from CSV to a Word letter.

04

Stay consistent

One value keeps one placeholder. “Smith, John” and “John Smith” share it, and a client redacted once is caught in every later file.

Reversible,
without a cloud.

The vault is an encrypted file on your machine. It is what lets redacted files go out and real values come back. An install with no settings sends nothing anywhere.

Encrypted at rest

Each value and its placeholder are encrypted together with AES-GCM. The vault file holds nothing readable, and only its owner can open it.

Placeholders work like keys

Each suffix is 10 random characters, about 50 bits. Nobody can guess one, so only someone holding a placeholder can rehydrate its value.

True redaction in PDFs

Values are removed from the document, not covered with a black box. Scanned pages are read with OCR, and Excel keeps its formulas, styles and pivots.
