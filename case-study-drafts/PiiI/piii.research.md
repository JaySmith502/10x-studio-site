## 2 · README excerpt

> **Detect and mask personal data before it ever reaches an AI chatbot.**
>
> PiiI is an open-source Chrome (Manifest V3) extension that intercepts your prompt as you send it to an AI chat platform, finds the personal data inside it, and offers to swap each value for an alias before the message leaves your browser. Detection and machine-learning inference run entirely on your machine. No prompt text, and no detected data, is ever sent to a server.

## 4 · Architecture sketch

**Top-level folders (src/):**

```
src/
  background/   service worker, NER bridge, storage, messaging
  offscreen/    ONNX NER pipeline (runs the model in an offscreen document)
  content/      content script, platform adapters, detection, substitution
    adapters/   one file per platform (selectors + send logic)
    detection/  regex detectors + merge
    fileScanner/ attachment extraction and scanning
  popup/        toolbar UI (alias map, audit log, whitelist)
  types/        shared types
  brand.tsx     brand mark
```

**Spine files / structure inspected:**

- `src/content/detection/regex/` — 8 regex detectors: `accountId`, `apiKey`, `creditCard`, `date`, `email`, `phone`, `ssn`, `url` (+ `index.ts` merge)
- `src/content/adapters/` — 7 platform adapters: `chatgpt`, `claude`, `copilot`, `deepseek`, `gemini`, `perplexity`, plus `grok` (shelved/unsupported) — `shared.ts` for common selector/send logic
- `src/offscreen/index.ts` — ONNX NER pipeline; runs in an offscreen document because MV3 service workers can't load onnxruntime-web
- `src/background/ner.ts` — NER bridge between content script and offscreen doc
- `src/content/fileScanner/` — attachment extraction (`extractors.ts`) + `ScanWarningModal.tsx`; supports `.txt .csv .md .log .json .docx .pdf`, 50k-char cap, fail-closed
- `src/content/submitFlow.ts` — the intercept → detect → review → substitute → send pipeline
- `src/popup/Popup.tsx` — alias map, audit log (CSV export), whitelist
